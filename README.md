# SQL Injection Vulnerable Flask Application

⚠️ This project is intentionally vulnerable and created strictly for educational cybersecurity learning purposes.

## Overview
This project is a vulnerable Flask web application developed to demonstrate common SQL Injection attacks using Python, Flask, and SQLite.

The application contains 8 intentionally vulnerable labs inspired by PortSwigger Web Security Academy.

## Features
- Hidden data retrieval
- Login bypass
- UNION SELECT attacks
- Column count detection
- Text column identification
- Cross-table data extraction
- Database version disclosure
- Schema enumeration

## Technologies Used
- Python
- Flask
- SQLite
- HTML/CSS
